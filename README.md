# Task 6: Subqueries and Nested Queries

## Objective
Use subqueries in SELECT, WHERE, and FROM.

## Tools Used
- MySQL Workbench
- MySQL Database

## Database
`threatsense_db`

## Tables Used
- `incidents`
- `alerts`

## SQL Concepts Used
- Subquery
- Nested Query
- IN
- EXISTS
- Derived Table

## Queries Performed

1. Used a subquery inside SELECT to calculate the total number of incidents.
2. Used a subquery inside WHERE with IN to filter incidents by severity.
3. Used a subquery inside FROM to create a derived table.
4. Used EXISTS to check related alert records.

## Outcome
Successfully used subqueries and nested queries to perform advanced query logic.
